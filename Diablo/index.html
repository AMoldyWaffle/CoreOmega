DIABLO

This is an offline, file:// build of the DiabloWeb project (d07RiV/diabloweb), which runs the original Diablo via WebAssembly, based on the devilution reconstructed source.

DIABDAT.MPQ is loaded automatically from the configured 11-part GitHub download. The parts are reassembled in memory before the game starts.

If the automatic download is unavailable, you can still select your own DIABDAT.MPQ below. A spawn.mpq file also works.
